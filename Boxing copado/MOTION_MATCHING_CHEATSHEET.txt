 1. CREAR EL SISTEMA EN UNITY (5 MINUTOS)
═══════════════════════════════════════════════════════════════════════════════

1. Crea un GameObject: MotionMatchingManager
2. Agrega 4 componentes (Add Component):
   ✅ RobotMotionSampler
   ✅ VRPlayerTracker
   ✅ MotionComparer
   ✅ MotionScoreSystem

3. Arrastra en Inspector:
   
   RobotMotionSampler:
   ├─ Robot Root: [Tu Robot_Kyle]
   ├─ Robot Animator: [El Animator del robot]
   └─ Sample Interval: 0.02
   
   VRPlayerTracker:
   ├─ Player Root: [XR Origin]
   ├─ Head Transform: [Main Camera]
   ├─ Left Hand Transform: [LeftHand Controller]
   └─ Right Hand Transform: [RightHand Controller]
   
   MotionComparer:
   ├─ Robot Sampler: [RobotMotionSampler]
   ├─ Player Tracker: [VRPlayerTracker]
   ├─ Weights: 0.4 / 0.4 / 0.2 (left/right/head)
   └─ Draw Debug Gizmos: ON
   
   MotionScoreSystem:
   ├─ Robot Sampler: [RobotMotionSampler]
   ├─ Player Tracker: [VRPlayerTracker]
   ├─ Motion Comparer: [MotionComparer]
   └─ Max Allowed Error: 0.5

 2. CÓDIGO BASE (COPIAR Y PEGAR)

    public void ExecutePunchTutorial(Animator robotAnimator, 
                                     MotionScoreSystem scoreSystem)
    {
        StartCoroutine(PunchRoutine(robotAnimator, scoreSystem));
    }

    private IEnumerator PunchRoutine(Animator robot, MotionScoreSystem score)
    {
        // 1. OPCIÓN 1: Robot demuestra
        Debug.Log("Robot va a demostrar...");
        score.StartRobotSampling();
        robot.SetTrigger("PunchLeft");
        yield return new WaitForSeconds(2.5f);
        score.StopRobotSampling();

        // 2. Espera y da instrucciones
        yield return new WaitForSeconds(1f);
        Debug.Log("¡Ahora imita el movimiento!");

        // 3. Jugador imita
        score.StartComparison();
        yield return new WaitForSeconds(4f);
        score.StopComparison();

        // 4. Resultado
        float finalScore = score.FinalScore;
        float avgError = score.AverageError;
        
        Debug.Log($"SCORE: {finalScore:F1}/100 (Error: {avgError:F4}m)");
    }

 3. CÓMO FUNCIONA - LA IDEA CLAVE
═══════════════════════════════════════════════════════════════════════════════

🤖 ROBOT DEMUESTRA (2.5 segundos):
   - Sistema samplea: Head, LeftHand, RightHand cada 0.02s
   - Guarda ~125 "fotogramas" locales
   - Estructura: List<MotionFrame> con posición + rotación

👤 JUGADOR IMITA (hasta 4 segundos):
   - Sistema compara en tiempo real
   - NO compara frame exacto
   - COMPARA por PROGRESO NORMALIZADO (0 a 1)
   
   Ejemplo:
     Robot duracion: 2s
     Jugador tiempo: 1s
     Progreso: 1/2 = 0.5 (50%)
     Se compara contra pose del robot EN 50% de la secuencia
   
   Resultado:
     ✅ Jugador más lento: OK si trayectoria es correcta
     ✅ Jugador más rápido: OK si trayectoria es correcta
     ❌ Trayectoria diferente: Score bajo

📊 SCORE FINAL:
   Error promedio ponderado:
     40% mano izquierda
     40% mano derecha
     20% cabeza
   
   Formula: Score = (1 - avgError / maxAllowedError) * 100
   
   Ajuste fácil: Max Allowed Error
     0.2 = MUY difícil
     0.5 = Equilibrado ⭐
     1.0 = Muy fácil

 6. PARÁMETROS AJUSTABLES
═══════════════════════════════════════════════════════════════════════════════

MotionScoreSystem:
  Max Allowed Error:
    0.2 = Muy fácil obtener 0
    0.5 = Equilibrado ⭐
    1.0 = Muy permisivo

MotionComparer (Pesos):
  Left Hand:  0.4 (importante)
  Right Hand: 0.4 (importante)
  Head:       0.2 (menos crítica)

RobotMotionSampler:
  Sample Interval: 0.02 (50 Hz)
    Más bajo = más preciso pero más data
    Más alto = menos preciso pero menos data

 7. TROUBLESHOOTING RÁPIDO
═══════════════════════════════════════════════════════════════════════════════

❌ "Score siempre 0"
   └─ maxAllowedError muy bajo
   └─ Aumenta a 0.7 o 1.0

❌ "no se encontraron algunos bones"
   └─ Animator no es Humanoid
   └─ Convierte a Humanoid

❌ Lineas amarillas no aparecen
   └─ Activar "Draw Debug Gizmos"
   └─ Ver Scene View (no Game View)

❌ "playerRoot no asignado"
   └─ Verifica que XR Origin esté asignado

}
