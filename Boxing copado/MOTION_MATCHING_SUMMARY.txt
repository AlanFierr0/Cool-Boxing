═══════════════════════════════════════════════════════════════════════════════
 🔑 CONCEPTO CLAVE: TIMING FLEXIBLE CON NORMALIZED PROGRESS
═══════════════════════════════════════════════════════════════════════════════

SIN Timing Flexible (❌ MALO):
```
Robot:    [====Frame0====][====Frame1====][====Frame2====]  (2s)
Jugador:  [==F0==][==F1==]                                 (1s, más lento)
Resultado: Comparación desalineada → Score bajo sin razón
```

CON Timing Flexible (✅ BUENO - Nuestro Sistema):
```
Robot:    [========Progress 0-1========]  (2s)
Jugador:  [====Progress 0-1====]         (1s, más lento)

Cuando jugador está en 50% → Se compara contra robot en 50%
Resultado: Timing flexible, score depende de TRAYECTORIA
```

Ventajas:
  ✅ Jugador puede ir lento: OK si trayectoria es correcta
  ✅ Jugador puede ir rápido: OK si trayectoria es correcta
  ❌ Jugador con trayectoria diferente: Score bajo (correcto)

═══════════════════════════════════════════════════════════════════════════════
 📐 SCORING PONDERADO (BOXING OPTIMIZED)
═══════════════════════════════════════════════════════════════════════════════

Fórmula:
  Score = (40% left_hand + 40% right_hand + 20% head)
  Score = (1 - error_ponderado / maxAllowedError) * 100

Por qué estos pesos en boxeo:
  40% Mano Izquierda → Golpes críticos
  40% Mano Derecha  → Golpes críticos
  20% Cabeza        → Postura (menos crítica pero válida)

Ajustable:
  maxAllowedError = 0.5   (configurable, por defecto equilibrado)
  0.2 = muy difícil
  1.0 = muy fácil

Ejemplo de Flujo Típico:

```csharp
// 1. Robot demuestra golpe
scoreSystem.StartRobotSampling();
robotAnimator.SetTrigger("PunchLeft");

// 2. Esperar 2.5 segundos

// 3. Detener sampleo
scoreSystem.StopRobotSampling();

// 4. Mostrar instrucción al jugador
// "¡Ahora imita el movimiento!"

// 5. Iniciar evaluación
scoreSystem.StartComparison();

// 6. Jugador imita durante 4 segundos

// 7. Detener evaluación y obtener resultado
scoreSystem.StopComparison();
float score = scoreSystem.FinalScore;          // 0-100
float error = scoreSystem.AverageError;        // Metros

// 8. Mostrar resultado
if (score >= 80) print("¡Excelente!");
else if (score >= 60) print("¡Bien!");
else print("Intenta de nuevo");
```
